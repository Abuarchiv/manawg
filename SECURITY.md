# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report privately through
[GitHub's private vulnerability reporting](https://github.com/Abuarchiv/manawg-app/security/advisories/new)
or by mail to info@manawg.com.

Include what is affected, how to reproduce it and what an attacker could do with it. You will get
an answer within 7 days. Once a fix is released, we publish an advisory and credit you unless you
prefer otherwise.

## Scope

- This repository and the official instance at app.manawg.com.
- Not in scope: self-hosted instances run by others (report to their operator), denial of service
  through traffic volume, and findings that need physical access to an unlocked device.

Please test only against your own account and WG, or a local instance. Do not access other
people's data and do not run automated scans against app.manawg.com.

## Supported versions

Only the latest release on `main` receives security fixes.
