## Why
The app contains multiple older brand treatments. The owner supplied a complete Brandbook v1.0 and requested its implementation so the design language no longer needs to be explained repeatedly.

## What Changes
Adopt the supplied monochrome identity, typography, organism mark, semantic money colors, opaque web surfaces, restrained motion, and PWA assets through existing shared components. Store the source and implementation contract in the repository.

## Capabilities
### New Capabilities
- `design-system`: the shared ManaWG brandbook contract for the existing web app.

## Impact
Global CSS, font loading, shared UI/chrome, financial presentation, identity assets and focused browser verification. No domain/API changes, production data writes or deployment.
